## Overview

Electron Executor is a Windows Roblox script executor packaged as a small Electron desktop application. Its interface is intended to provide a straightforward way to load and execute Lua or other scripts from a local program instead of relying on a busy browser-based process.

A central part of the application is its built-in script hub, complemented by automatic updates for newer builds and evolving Roblox scripting requirements. Users seeking a Windows Lua executor with batch processing, retained queue management, and multilingual interface support may find these capabilities useful.
